# frompt

A smart prompt builder that helps you craft better AI prompts through a conversational interface. Just describe what you want in a few words, and frompt will guide you through building a detailed, effective prompt.

## Features

- **Conversational prompt building** — chat-style interface that asks you the right questions
- **Multi-track support** — visual (Midjourney, DALL-E, Stable Diffusion), writing, coding, and more
- **Smart keyword detection** — automatically categorizes your request and tailors the flow
- **Prompt history** — revisit and reuse past prompts
- **Settings** — customize to your workflow

## Usage

1. Open `index.html` in your browser
2. Tell frompt what kind of prompt you want to build
3. Follow the conversation to refine your prompt
4. Copy the final prompt and use it anywhere

## Tech

- Vanilla HTML, CSS, JavaScript — no frameworks, no dependencies
